Sincronización de Proyectos

Operaciones
Enviar y Recibir

Primero se realizará el envío de todos lo datos registrados y luego se recibirán los datos desde la base de datos de Foncodes.
Sólo recibir

No se enviarán los datos registrados, se recibirá la información de la base de datos de Foncodes. Cualquier registro sin enviar será eliminado.
Reiniciar

Se eliminará y volverá a cargar toda la información de proyectos.
No sincronizar proyectos

No se sincronizará la información de los proyectos.
